## 4. 내 동네 개별 병원 가격 직접 확인하는 법

**웹**: https://www.hira.or.kr/npay/index.do → 상단 바로가기 버튼 **`대상포진`** 클릭(스카이조스터·조스타박스·싱그릭스 3종이 한 번에 선택됨) → 왼쪽에서 시·도 / 시·군·구 / 읍·면·동, 의료기관 종별 선택 → `확인` → 병원별 금액(최저·최고) 목록이 뜨고, 지도 보기·병원명 검색·`세부정보`도 가능.

**모바일 앱 '건강e음'**: 메뉴 → 비급여 진료비용 정보 → 동일한 방식(항목 검색창에 `대상포진` 입력).

**지역별 평균 비교 화면**: 항목 선택 후 '지역별 금액 비교'(대한민국 지도) 화면에서 위 표와 같은 시·도별 최저/최고/평균/중간금액을 볼 수 있다.

## 5. 해석 포인트

- **지역 간 차이는 크지 않다.** 세 백신 모두 시·도별 *중간금액*은 사실상 동일하거나 1만 원 수준 차이(스카이조스터 14만 vs 15만, 조스타박스 15만 vs 17만, 싱그릭스는 전 지역 25만). 즉 "어느 지역이 싸냐"보다 **같은 동네 안에서 어느 병원이냐**가 훨씬 크게 갈린다.
- **같은 백신인데 병원별 최저~최고 차이가 2~4배.** 예: 싱그릭스 15만~45만, 조스타박스 7.5만~40만. 실제 절약은 동네 의원 몇 곳 가격을 비교해서 얻는다.
- **종별로는 상급종합병원이 싱그릭스 기준 오히려 평균이 낮고(24.0만), 의원 평균이 24.8만.** 다만 상급종합병원은 접종만 받으러 가기 어렵고 진찰료가 따로 붙을 수 있다.
- **싱그릭스는 2회 접종** → 표의 금액 × 2가 실제 총액(전국 중간금액 기준 약 50만 원).
- 스카이조스터 최저 8,314원(경기 소재 종합병원) 같은 값은 자료 입력 오류이거나 특수한 조건일 가능성이 높으니 그대로 믿지 말 것.
- 65세 이상 등 일부 지자체는 대상포진 백신 접종비를 지원한다(지자체별 상이). 보건소에 문의하면 무료·할인 대상 여부를 알 수 있다.

## 6. 이 문서 만든 방법 / 한계

심평원 비급여 공개 서비스(`/npay`)의 지역별 금액 조회 API(`/rb/selectPlcSclAmtList.do`)를 직접 호출해 3개 백신 × 17개 시·도 × 종별 데이터를 수집했다.
병원 단위 목록 API(`/rb/selectNpayDamtPubList.do`)는 이 세션 환경에서 계속 서버 오류(500)를 반환해 **개별 병원 이름·주소·금액까지는 수집하지 못했다.** 개별 병원 비교는 위 4번 방법으로 직접 조회해야 한다.
